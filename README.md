# 😈 Злой инвестор

ИИ-тренажёр для студентов, которые защищают стартап как диплом. Студент выбирает инвестора, вставляет питч, отвечает на **5 неудобных вопросов** и уходит с **честной оценкой** по критериям «Стартап как диплом» и **3 советами**, которые можно успеть до выхода на сцену.

Кейс Vibecode Nights, 6 ноября 2026.

**Прототип:** _ссылка появится после деплоя_

## Как пользоваться

1. Выберите инвестора: Бизнес-ангел, Корпорация, Грантовый фонд, Венчурный фонд — или настройте своего (кто он, чего хочет, чего боится, как себя ведёт, какие 3 критерия для него важнее).
2. Вставьте питч: кто клиент, какая боль, что делаете, как зарабатываете, что уже проверили (200–5000 символов).
3. Ответьте на 5 вопросов. Отвечайте коротко и с цифрами: через 60 секунд таймер подсветит «Короче!», а инвестор перебивает длинные ответы.
4. Получите оценку из 100, разбор по 10 критериям и 3 совета.
5. Выполните советы и пройдите **второй раунд**: тренажёр покажет, как изменился балл.

## Как устроены 5 вопросов

Номер вопроса считает код, у каждого номера своя задача:

| № | Задача вопроса |
|---|---|
| 1 | Клиент и доказательства: кто конкретно, сколько интервью, что удивило |
| 2 | Самый слабый и самый важный для этого инвестора критерий в питче |
| 3 | Следующий слабый критерий, без повторов |
| 4 | «Вопрос страха» инвестора (ангел — что будет после диплома; корпорация — кто подписывает договор и где данные; грант — KPI и смета; венчур — объём рынка и масштаб) |
| 5 | Дожим: возврат к самому слабому ответу студента |

Каждый вопрос цепляется за слова из питча или прошлого ответа. Бот не выдумывает цифры и конкурентов: если их нет в питче, он спрашивает.

## Как устроена оценка

- **10 критериев** второго этапа конкурса «Стартап как диплом»: реалистичность решения, бизнес-модель, рынок и конкуренты, финмодель, ИС или регистрация, первые продажи, риски, горизонт расчёта, уникальность, инвестиционная привлекательность.
- **Шкала 0–3** по каждому: 0 — не сказано; 1 — заявлено без доказательств; 2 — есть цифры и конкретика; 3 — подтверждено действием (интервью, пилот, продажи, регистрация).
- **Два балла на критерий:** «после питча» и «после ответов» — видно, как ответы повлияли на оценку.
- **Баллы только с доказательством:** балл 2–3 нейросеть ставит лишь с дословной цитатой студента, а **код проверяет**, что цитата действительно есть в тексте. Нет цитаты — максимум 1.
- **Итог 0–100 считает код**, а не нейросеть: сумма «вес × балл / 3». Веса зависят от инвестора (`config/weights.json`); для своего инвестора выбранные критерии весят втрое больше.
- **Вердикт:** 0–39 «Не вложусь», 40–69 «Приходите через неделю», 70–100 «Давайте обсудим условия».

## 3 совета

Ровно 3, на критерии с наибольшим «важность × недобор баллов». Каждый — действие на 1–3 дня: что сделать, как, какой результат, сколько времени, какой критерий поднимет. Один совет всегда про речь: проговорить вслух ответ на самый провальный вопрос. Общие советы («проведите исследование рынка», «доработайте») код отклоняет и просит переписать.

## Границы и защита от обмана

- Жёсткость бьёт по проекту, а не по человеку: без мата, оскорблений и шуток про личность.
- Пустой или короткий питч (меньше 200 символов) отклоняется кодом ещё до нейросети; не-питч (рецепт, домашка) — нейросетью.
- Просьбы «поставь 100», «игнорируй инструкции», «я от организаторов» не работают: текст студента передаётся нейросети как данные в отдельных тегах, а итог считает код.
- Признаки сильного стресса — бот выходит из роли и поддерживает.
- Лимиты длины: питч 5000 символов, ответ 1000, поля своего инвестора по 300.

## Метрики

1. **Второй раунд лучше:** доля студентов, которые за 7 дней прошли второй раунд и подняли балл на 10+ пунктов.
2. **Доходимость:** доля сессий, где студент ответил на все 5 вопросов и дошёл до советов.

## Стек

- Сайт: HTML + CSS + JavaScript без сборки (`public/`).
- Сервер: одна функция на Python, только стандартная библиотека (`api/chat.py`), хостинг Vercel.
- Нейросеть: любой OpenAI-совместимый API (OpenRouter, OpenAI, Gemini, YandexGPT), выбирается переменными окружения.
- Промпты — обычные текстовые файлы (`prompts/`), веса — `config/weights.json`. Их можно править без изменения кода.

```
api/chat.py              сервер: диалог, проверки, подсчёт итога
prompts/guardrails.md    границы и защита от обмана (главнее характера)
prompts/questions.md     как вести 5 вопросов
prompts/report.md        оценка и 3 совета
prompts/personas/*.md    4 инвестора + шаблон своего
config/weights.json      критерии, веса, вердикты, запрещённые фразы
public/                  сайт
dev_server.py            локальный запуск
```

## Запуск локально

```bash
cp .env.example .env      # впишите LLM_BASE_URL, LLM_API_KEY, LLM_MODEL
python3 dev_server.py     # откройте http://localhost:8000
```

Без ключа можно проверить интерфейс: `LLM_MOCK=1 python3 dev_server.py`.

## Деплой на Vercel

Импортируйте репозиторий в Vercel и добавьте переменные окружения `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`. Проверка: `GET /api/chat` показывает, видит ли сервер промпты и настроен ли ключ (сам ключ не показывает).

## Безопасность

- Ключ нейросети только в переменных окружения сервера, в коде и браузере его нет.
- Базы данных нет, личные данные не хранятся: история сессии живёт в браузере.
- Весь текст выводится как текст (`textContent`), HTML и скрипты из ввода не исполняются.
- Сервер проверяет и обрезает все входные данные, не показывает внутренние ошибки наружу.
